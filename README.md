# Interactive World Map

An interactive Angular application created as part of my Bachelor’s degree in Software Engineering at Western Governors University.

## Overview

This project uses Angular and TypeScript to create an interactive world map. The application connects to the World Bank API to retrieve country information and presents the information through the map interface.

## Technologies

- Angular
- TypeScript
- HTML
- CSS
- World Bank API
- REST API integration
- SVG

## What I Worked On

- Built Angular components
- Created an interactive SVG-based world map
- Connected the application to the World Bank API
- Retrieved and displayed country information
- Used TypeScript services for API communication
- Styled the application with CSS

## Running the Project

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
ng serve
```

Then open the local address shown by Angular in your browser.
